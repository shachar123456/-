## מכ״ם גשם ישראל

אפליקציית מכ״ם גשם בזמן אמת לישראל — קובץ HTML יחיד תחת [`mekam-geshem/`](./mekam-geshem/).

> ממשק מינימלי: מפה במסך מלא + כפתורי מיקום/ערים.

### מה יש בפנים

* מפה אינטראקטיבית במסך מלא עם שכבת מכ״ם חיה
* שורת מיקום: המיקום שלי, כל הארץ, וערים מהירות
* סריקת מכ״ם חיה אחת עם פייד ענן רך; קרוספייד כשמגיעה סריקה חדשה
* בדיקת RainViewer כל 3 שניות; תוויות יישובים בעברית
* גיבוי IMS / Windy נשאר בקוד אך אינו חשוף בממשק המפושט

### הרצה מקומית

```bash
cd mekam-geshem
python3 -m http.server 8000 --bind 127.0.0.1
```

פתחו את [http://127.0.0.1:8000](http://127.0.0.1:8000).
